# GOLD Scalping Pro [XAU/USD] ─ TradingView Pine Script

## ファイル構成

| ファイル | 用途 |
|---|---|
| `gold_scalping_strategy.pine` | **メイン**。バックテスト + シグナル + SL/TP表示 |
| `gold_scalping_indicator.pine` | **サブパネル**。StochRSI専用ウィンドウ（メインと併用） |

---

## 戦略概要

### エントリー条件

**ロング (BUY)**
1. EMA 8 > EMA 21（上昇トレンド）
2. Stochastic RSI の K線が D線を**下から上に**クロス
3. K値が 80 未満（過熱していない）
4. ロンドン/NYセッション時間内（UTC 07:00–22:00）

**ショート (SELL)**
1. EMA 8 < EMA 21（下降トレンド）
2. Stochastic RSI の K線が D線を**上から下に**クロス
3. K値が 20 超（売られすぎていない）
4. セッション時間内

---

### リスク管理（ATR基準）

```
エントリー価格を基準に ATR で動的計算

⛔ 損切り (SL)  = ATR × 1.5
🎯 TP1          = ATR × 2.0  → 40%決済 (RR 1:1.3)
🎯 TP2          = ATR × 3.0  → 35%決済 (RR 1:2.0) ← バックテスト基準
🎯 TP3          = ATR × 4.5  → 25%決済 (RR 1:3.0)
```

### 実運用での決済手順
1. **TP1到達** → 40%利確 & SLをブレイクイーブン（エントリー価格）に移動
2. **TP2到達** → 35%利確 & SLをTP1に移動
3. **TP3到達** → 残り25%全決済

## TradingViewへの入れ方

### メインチャート
1. TradingViewを開き `XAUUSD` チャートを表示
2. 時間足を `1分` / `3分` / `5分` に設定
3. 上部メニュー → **Pine Editorを開く**
4. `gold_scalping_strategy.pine` の内容を貼り付け
5. **「チャートに追加」** をクリック
6. 右下のストラテジーテスターでバックテスト結果を確認

### サブパネル（オプション）
1. 新しいPine Editorを開く
2. `gold_scalping_indicator.pine` の内容を貼り付け
3. **「チャートに追加」** → 下部にStochRSIパネルが表示される

---

## アラート設定

1. チャート上で右クリック → **「アラートを追加」**
2. 条件: `GOLD Scalp Pro` を選択
3. 使用可能なアラート:
   - `🟢 GOLD BUY シグナル` ─ ロングエントリー
   - `🔴 GOLD SELL シグナル` ─ ショートエントリー
   - `⚡ GOLD スキャルピング シグナル` ─ 両方まとめて

---

## バックテスト設定

ストラテジーテスターで確認できる指標：
- **勝率 (Win Rate)**: 目標 50%以上
- **プロフィットファクター (PF)**: 目標 1.3以上
- **最大ドローダウン**: 10%以下を推奨
- **純利益 (Net Profit)**: プラスであること

> ⚠️ バックテストはTP2（RR 1:2）をメインターゲットとして計算。  
> 実運用でTP1/TP2/TP3に分割決済するとさらにドローダウンが改善される。

---

## 推奨設定

| 項目 | 推奨値 |
|---|---|
| 時間足 | 1分 / 3分 |
| セッション | ロンドン〜NY (14:00–07:00 JST) |
| ATR期間 | 14 |
| リスク/トレード | 資金の1〜2% |
| 最大同時ポジション | 1 |

---

## 注意事項

- 経済指標発表30分前後はトレードを避ける（FOMC、NFP、CPIなど）
- スプレッドが広い業者ではTP1が取りにくくなる
- バックテスト結果は過去のパフォーマンスであり将来を保証しない
